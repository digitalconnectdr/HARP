# HARP W5 — 2026-10-21

Research-only checkpoint. Official Samsung documentation describes Wi-Fi Sharing, which allows supported Galaxy phones to share an existing Wi-Fi connection through a user-enabled hotspot. A cooperating Phone B could therefore provide an app-free access path for Phone A, subject to firmware compatibility, consent, and authorized upstream access. No device testing was performed.

Source: https://www.samsung.com/us/support/answer/ANS10002546/

This does not provide access through unknown, nonparticipating devices. Further work: verify model compatibility and calculate volunteer availability. GitHub Actions remain unused.
